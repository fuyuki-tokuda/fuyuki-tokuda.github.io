東北大学 未踏スケールデータアナリティクスセンター 助教

視覚フィードバック制御とロボットマニピュレーションを研究しています。機械学習を用いた精密な位置決め、双腕ロボットによる布の操作、縫製工程の自動化に取り組んでいます。

研究を見るプロフィール
01 / PERCEPTION & CONTROL

学習に基づく視覚サーボ

目標画像と現在画像の差から、位置決めに必要な動きを推定。

02 / DEFORMABLE OBJECTS

布の位置・形状・柄合わせ

双腕の協調動作で、位置と変形を同時に扱う。

03 / SYSTEMS

治具を使わない縫製

布の操作から縫製工程までを、一つのシステムへ。

すべての研究

IEEE RA-L / 2026

布の柄を合わせて、重ねる

Transformer Driven Visual Servoing for Fabric Texture Matching Using Dual-Arm Manipulator

異なる柄の布にも対応する、Transformerに基づく視覚サーボ。双腕の力制御と組み合わせ、張力を保ちながら位置合わせと重ね合わせを行います。

研究の内容Paper / DOI

IEEE ICMA / 2025

布の取り出しから、縫製・搬出まで

Robotic Sewing System for Fully Automated Fabric Picking, Stacking, Loading, Sewing, and Unloading

取り出し、積み重ね、搬入、縫製、搬出をつなぐ自動縫製システム。専用治具を使わず、複数の工程を一台のPCから制御します。

研究の内容Paper / DOI

IEEE TASE / 2025

治具に頼らず、曲線を縫う

Fixture-Free 2D Sewing Using a Dual-Arm Manipulator System

双腕で布の位置と張力を制御し、カメラで縫い線を追跡。重ねた2枚の布を、専用の固定治具なしで縫い合わせます。

研究の内容Paper / DOI

IEEE ICRA / 2023

布の位置決めと、しわ伸ばしを同時に

CNN-based Visual Servoing for Simultaneous Positioning and Flattening of Soft Fabric Parts

カメラ画像と力・トルクの情報から双腕の動作を求め、布を目標位置に合わせながら平らにします。
